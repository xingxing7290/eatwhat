# 菜谱详情与图片反馈

菜谱详情和关联回忆独立加载；回忆读取失败不会隐藏已加载的菜谱。照片预览使用已保存的图片地址，并在读取失败时显示占位图。相关回忆入口按记录编号打开当前家庭的数据。

图片反馈提交后，如果响应丢失或内容不完整，页面会暂时阻止重复提交，允许用户读取待修正反馈并决定是否重试。反馈列表最多返回 200 条，页面会在达到上限时提示可能不完整；即使列表没有匹配项，也不能证明先前请求不会稍后完成。核对状态只保存在当前页面，接口未建立图片反馈的唯一约束，跨设备或重新打开页面仍可能产生重复反馈。离开页面前会提示未确认的结果。

反馈记录的菜谱、创建者和处理人按当前家庭过滤；历史跨家庭引用不会展示关联对象。部署前应保留私有备份，在隔离环境验证旧数据和图片地址；不要自动修改即将到期的旧服务器。
