# 饭桌回顾：统计与安全边界

Web 端按所选月份或年份展示当前家庭的排餐、饭后回忆、照片、菜品排行和心情。排餐数字是记录中的菜品条目数，包括关联菜品已不可用的条目，并不代表实际食用次数。菜品排行将可读取的排餐条目与回忆中的菜品关联次数相加；同一餐可以在两处各计一次。历史归档菜品仍参与回顾，但“当前小家”的菜品和收藏数量只统计当前未归档菜品；当前想吃数量也不是所选期间的统计。照片总数与最多 12 张的预览数量不同。

接口对回忆和排餐中的菜品、创建者及参与者引用按家庭过滤，不返回跨家庭引用的关联详情。页面只接受明确返回 `supportsHouseholdScopedReview: true` 的服务端数据；旧服务器没有此能力标志时页面会拒绝展示回顾。回顾响应和错误不会写入客户端 API 调试历史。

该保护不改变上传文件 URL 的访问控制；如果现有服务器允许公开访问图片地址，这一改动不会使图片本身变成私有文件。各项统计来自多次数据库查询，并非事务性快照；查询期间发生的修改可能暂时造成数字不完全一致。

月份与年份限制在 2000 至 2100 年。页面会校验服务器返回的周期和数据结构，处理请求乱序、加载失败和空状态。客户端和服务端需要一起发布；升级前应备份数据并验证家庭隔离、图片访问策略及历史记录。
