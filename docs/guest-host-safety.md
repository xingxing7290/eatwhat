# 宴请管理与安全边界

Web 主人端可创建宴请、复制或更换访客链接，查看点菜汇总和客人备注，以及锁单、重新开放、完成或取消宴请。列表最多展示最近 30 场。访客链接是访问凭证，持有者可查看当前家庭的公开菜单及参与点菜；应只分享给受邀客人，公开日志和备份中不应包含链接或安全创建凭证。

新版服务明确声明能力后，Web 才允许安全创建和修改；旧服务的宴请可查看，但页面不会退回无条件写入。创建使用按家庭和随机凭证派生的 MongoDB 唯一 `_id`，无新增索引；同一凭证和相同内容可安全重试，内容变化会被拒绝。创建请求还携带预期家庭编号，家庭已切换时拒绝写入。待处理凭证保存在当前浏览器标签页的会话存储中，关闭标签页、清除存储或切换家庭后不保证能继续恢复；放弃重试再创建可能重复，需先与家人核对。

宴请信息、状态和换链操作携带版本并使用条件更新；并发变化会产生冲突。网络错误或响应不完整时，页面暂停修改与复制旧链接，要求读取最新状态并由用户确认；已发送请求仍可能在核对后迟到完成。旧客户端的无条件写入仍保留兼容，直接数据库写入或未升级服务不一定遵循这些保护。

锁单、完成、取消和更换链接会阻止之后重新通过校验的请求，但对已通过校验、仍在处理中的访客请求不是事务屏障，后者可能稍后完成。更新状态后可刷新点菜汇总并再次核对。已过期的链接不能重新开放或更换；历史点菜记录不会因换链而删除。上线前应在隔离环境验证，并保留私有数据库和图片备份。
