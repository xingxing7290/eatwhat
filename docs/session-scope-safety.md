# 标签页账号和家庭切换保护

Web 页面将自己的请求绑定到打开时的账号令牌以及已知用户、家庭编号。其他标签页更换令牌，或通过共享的浏览器存储切换已知账号/家庭时，旧页面会显示提示并暂停新的受保护 API 请求；已输入的草稿留在页面，用户可先复制，再自行确认重新加载。已发出的请求仍可能在服务端完成；检测到变更后才到达的响应不会被旧页面当作当前数据使用，涉及写入时应核对结果。登录和注册请求不受此保护拦截；本页正常登录或完成家庭切换后会更新绑定。

这不是服务端事务锁或跨设备变更通知：另一设备修改家庭但没有同步到本浏览器存储时，本页无法仅凭此机制知道变化。令牌或家庭切换与正在处理的请求也不是原子操作；重要写入仍需服务端的家庭范围校验、版本控制或幂等保护。浏览器存储被清除或禁用、资料缺少家庭编号时，保护能力受限。访客点菜页是独立的公开页面，不使用这一登录会话机制。
