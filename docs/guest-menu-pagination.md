# 访客菜单分页与兼容性

新版访客页面使用服务端分页、搜索和分类，不再把 600 道菜作为完整菜单。每页最多 24 道，搜索覆盖菜名、分类、描述、标签和口味；分类计数基于当前搜索结果，跨页及筛选切换不会清空已选菜品。搜索词按普通文本处理，不作为正则表达式执行。

分页能力由服务端明确声明。旧接口不带分页参数时仍最多返回 600 道，以兼容旧客户端；新页面遇到旧服务时会继续提供本地筛选，并在达到上限时明确提示结果可能不完整。菜单请求失败、返回不完整或结果过期时，页面不会把旧结果当成当前筛选结果，而是提供重试或等待最新请求。

分页查询和数量统计不是事务快照；菜品被家人同时增加、归档或修改时，相邻页面的内容和总数可能变化。已选菜品保留在点菜单，服务端在提交时再次检查是否可用。归档检查与订单写入仍有并发窗口，详见 `meal-archive-safety.md`。上线前应使用隔离数据验证分页、搜索、旧服务兼容及点菜提交，不要自动修改旧服务器。
