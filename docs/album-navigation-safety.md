# 首页照片定位

首页最近照片链接包含回忆编号、照片在回忆中的序号、照片内容摘要和月份，不包含照片 URL 或图片数据。新版相册定位接口按当前家庭和月份查找照片，并校验摘要；图片被替换、删除或不属于当前家庭时不会打开另一张照片。打开目标页面后还会再次比对照片地址，避免两次请求之间数据变化造成误定位。

定位与分页读取不是同一事务：如果家人同时增加、删除或调整照片，目标可能移到其他页，页面会提示重新定位。旧版首页数据不含定位标识时，链接只能打开对应月份；如果首页已提供标识而相册接口仍为旧版，则页面提示手动查找。新定位接口使用 MongoDB 的 `$setWindowFields`（MongoDB 5.0 及以上）；部署前应在隔离环境验证数据库版本、家庭隔离和回退行为，不要直接修改即将到期的生产服务器。
